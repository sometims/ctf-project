# 🧰 00 · 资料与工具（跨题型通用）

> 本文件夹不放具体题目，集中收纳**所有分类共用的工具脚本、速查卡、工具说明书**。
> 各分类的 `README.md` 会引用这里的工具；做题时按需取用。

## 一、工具清单

| 工具 | 用途 | 说明书 |
|---|---|---|
| `sensitive_scan.py` | 敏感文件扫描（robots/.bak/.swp/git 自动挖 + 搜 flag） | `工具箱说明书.md` |
| `combine_scan.py` | 目录扫描 + 敏感文件 二合一 | `工具箱说明书.md` |
| `mini_scanner.py` | 目录扫描（带「假 200」识别，避免误判） | `工具箱说明书.md` |
| `git_search.py` | 下载/恢复 `.git` 后自动搜 flag | `工具箱说明书.md` |
| `swp_extract.py` | `.swp` 临时文件恢复为源码 | `工具箱说明书.md` |
| `php_eval_chain.py` | `$$` 变量-variable eval 链自动爆破模板 | `工具箱说明书.md` |
| `serforge.py` | PHP 序列化串构造器（支持 public/protected/private、嵌套对象） | `serforge使用说明.md` |
| `ssrf_scanner.py` | SSRF 万能探测器（五步全流程：验证/黑名单测绘/网关绕过/内网横扫） | `ssrf_scanner说明书.md` |
| `curl构造器.html` | 填空式 curl 命令生成器：选方法/填 URL/加头/选 body，实时生成可复制命令；带逐行解释和 42 条选项速查，全部标注「常用 / 按需」 | 页面内置（双击用浏览器打开） |

## 二、速查资料

- `Web最小工具集速查卡.md` —— curl 万能骨架（怎么发/带什么/怎么收），随身速查。
- `curl命令详解与万能模板.md` —— curl 参数逐项详解 + 可直接改的指令模板 + 七个常见坑。
- `curl构造器.html` —— 不用背语法：填空自动拼命令，右侧逐行解释每个参数，底部附完整选项速查表；支持 Bash / PowerShell / CMD 三种引号规则。
- `Web笔记08-工具箱手册.md` —— 各工具用法 + 适用场景对照。
- `工具箱说明书.md` —— 6 个通用工具的统一说明。
- `serforge使用说明.md` / `ssrf_scanner说明书.md` —— 两个专项工具独立说明。

## 三、怎么用

1. 做题前先看对应分类的 `README.md`，里面会点名「这道题该用哪个工具」。
2. Python 工具都是**零依赖脚本**，统一用 `python 脚本名.py -h` 看参数；`curl构造器.html` 直接双击用浏览器打开，无需联网。
3. 新写的通用脚本也丢进这个文件夹，并在本表登记。
