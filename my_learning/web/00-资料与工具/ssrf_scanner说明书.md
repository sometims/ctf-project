# 🔧 ssrf_scanner.py 说明书（SSRF 万能探测器）

## 这是什么

对付"**URL 分析器**"类题目的通用探测工具——网站让你输入一个 URL、服务器替你访问并回显结果的（SSRF 漏洞），用这个工具一条命令完成全套探测。

> 类比：钥匙串。常见锁的钥匙（回环变体/内网网段/端口）都配好了，换题只换"门牌号"（参数）。

## 什么时候用它

看到以下特征之一，就可以掏出它：

- 表单只有一个输入框："待分析URL" / "请输入URL" / "URL检测"
- 功能描述是"分析 URL" / "URL 安全检测" / "威胁情报"
- 你提交 `http://example.com` 后，页面显示了 example.com 的**响应头或响应体**

## 怎么用

```bash
# 最简用法（只给靶机地址）
python ssrf_scanner.py -u http://challenge.qsnctf.com:40555/

# 完整用法（指定参数名/网段/端口）
python ssrf_scanner.py -u http://靶机/ -p url_to_analyze -n 172.17.0.0/24 -c 15 --ports 80 5000
```

## 参数表

| 参数 | 默认值 | 含义 | 什么时候要改 |
|---|---|---|---|
| `-u` | 无（必填） | 分析器页面的地址 | 每题必改 |
| `-p` | `url_to_analyze` | 表单里 URL 参数的名字 | 参数名不同时（看页面源码的 name=） |
| `-n` | `172.17.0.0/24` | 要扫的内网网段 | 扫不到时换 `10.0.0.0/24`、`192.168.1.0/24` |
| `-c` | `10` | 网段里扫前几个 IP | 服务不在前 10 个时调大 |
| `--ports` | `80` | 要扫的端口 | 内网服务不在 80 时，如 `--ports 80 5000 8080` |
| `-t` | `8` | 单请求超时秒数 | 网络慢时调大 |

## 它替你做的 5 步（= 做题心法的代码版）

```
① 验证：喂 http://example.com，看服务器是否真的代访问（不是 SSRF 就别浪费时间）
② 读本地：file:///etc/passwd、/flag、/flag.txt（很多题 flag 就在这）
③ 绕回环：127.0.0.1 的 16 种写法（短格式/十进制/十六进制/IPv6/特殊域名）
④ 扫内网：你给的网段前 N 个 IP × 端口（容器靶机默认 172.17.0.x）
⑤ 搜 flag：内网每个页面的 HTML 里搜 flag{...}（通用正则，自动识别）
```

## 输出怎么读

```
✅  = 服务器访问成功，有回显（有戏）
⛔  = 被拒/无内容（这条路死了）
🎯  = 找到 flag 了！（恭喜，收工）
```

## 常见问题

**Q：扫出来一堆内网服务，哪个才是这题的？**
A：先看哪些页面里有 🎯 flag。多个候选就都提交验证。没有 flag 的页面可能是别的题目的容器（平台共享网络），跳过即可。

**Q：网段扫完全灭？**
A：换网段重试：`-n 10.0.0.0/24` → `-n 192.168.1.0/24` → `-n 172.18.0.0/24`。再不行检查 -p 参数名对不对。

**Q：提示"目标不像是 URL 分析器"？**
A：这网站不是 SSRF（可能只是普通表单）。别硬用，先人工看页面功能。也可能是 -p 参数名不对，看页面源码里 input 的 name。
