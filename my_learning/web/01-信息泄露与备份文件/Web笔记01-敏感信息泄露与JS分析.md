## 一、核心思维（最重要，先记这个）

1. **网页上的一切都不是秘密。** HTML、CSS、JavaScript 全部会原样发给浏览器——所谓"前端"就是完全透明的。
2. **先读题面。** 题名、描述、标签都在主动剧透考点（例：「我Flag呢？」→ flag 藏起来了；标签「源码泄露」→ 直接告诉你去翻源码）。
3. **三步法**：自己试 → 卡住用搜索引擎查 → 还不行看官方 WP，看懂后合上重做。
4. **"网页游戏" 90% 不是给你玩的** —— 它是披着游戏外衣的代码分析题。读代码比通关快一万倍。

---

## 二、三种题型套路

### 题型 A：查看源代码 / 敏感信息泄露
**flag 藏在**：HTML 注释、隐藏元素、外链的 .js/.css 文件、robots.txt

```
操作：
  F12                     → 打开开发者工具
  Ctrl+U                  → 直接看整页源码（最省事）
  F12 → Sources           → 看所有加载的 JS/CSS 文件
  F12 → Network           → 看页面发出的每个请求
```

**要找**：`<!-- 注释 -->`、`<div style="display:none">`、`<script src="xxx.js">` 里的 xxx.js

### 题型 B：.git 源码泄露
**原理**：git 保存全部历史，即使后来删了/覆盖了，**旧版本永远留在 .git 目录**。网站若把 .git 暴露在公网，任何人都能下载并翻出所有历史——包括"已删除"的 flag。

```
① 探测（浏览器访问或 curl）：
  curl http://靶机/.git/

② 下载泄露的 .git 目录：
  git-dumper http://靶机/.git/ dump
  （dump 是存放目录名，随便起）

③ 翻历史找 flag：
  cd dump
  git log --oneline --all    ← 列出所有提交
  git log -p --all           ← 看所有提交的代码改动（flag 最常在这）
  git show <提交号>           ← 单独看某次提交
```

> 场景重现：出题人某次提交带上了 flag，后来想销毁，"重新 pull"覆盖——但历史里那一条还在。

### 题型 B2：Vim 交换文件（.swp）泄露 ★
**原理**：Vim 编辑文件时在同目录生成隐藏交换文件 `.文件名.swp`（还有 .swo/.swn）。网站把它留在 Web 目录 → 下载恢复出**被编辑的源码**（即使原文件删了也还在）。

```
探测：curl http://靶机/.index.php.swp   → 200+有内容=存在
下载：curl -s http://靶机/.index.php.swp -o index.php.swp
提取：python swp_extract.py index.php.swp   （工具在我的 web/ 目录）
看hex：xxd index.php.swp   （二进制头会露：vim版本/系统/用户名）
```
> ⚠️ .swp 是**二进制文件**，直接打开是乱码——要"提取"而不是"打开"。
> 💡 它还能泄露**元数据**：出题人的 Vim 版本、Kali 系统、用户名（信息收集最爱）。

### 题型 B3：命令执行漏洞 RCE（eval(system())）★
```php
eval(system($_POST['cmd']));   // cmd 可控 → 服务器执行任意命令
```
- 攻击者控制 `cmd` → `cat /flag`、`ls /`、`whoami` 任玩
- 这是**最严重漏洞**：等于拿到服务器终端
- 常和"文件泄露→读源码→发现漏洞"组合出现（Vim yyds 就是这个套路）

### 题型 C：JS 分析 / 网页游戏
**原理**：游戏规则写在 JS 里，flag 要么硬编码在源码中，要么通关才显示。但"通关条件"也是代码——不需要真玩。

```
① 找到游戏 JS 文件
  F12 → Sources 看文件树；或 curl 抓 HTML，找 <script src="...">
  例：curl -s http://靶机/ -H "User-Agent: Mozilla/5.0" | grep -i script

② 下载 JS 源码
  curl -s http://靶机/src/game.js -o game.js

③ 搜关键词（见下方"flag 狩猎正则"）
```

> 导弹迷踪实战：第 47 行 `if (mLevel === 6) {return 'GOT F|L|A|G {y0u_w1n_th1s_!!!}'}` —— flag 直接写在源码里。

### 题型 D：元素审查 → 脚本注释线索 → JSFuck（1zjs 实战 ★新）
**套路链**：审查元素找脚本 → 通读 JS（**重点看注释**）→ 注释里藏路径/线索 → 访问 → 识别混淆 → 执行

```
① 审查元素（F12 / Ctrl+U）→ 发现 <script src="xxx.js">
② 下载 JS，通读，特别是【注释】—— 版权注释等"最无害"的地方最爱藏线索
   例：tslib 版权注释里写着 "Your gift just take it : /f@k3f1ag.php"
③ 访问注释给的文件 → 返回一坨只有 [ ] ( ) ! + 的代码 = JSFuck
④ JSFuck 是合法 JS，直接 eval 执行：
   node -e "console.log(eval(require('fs').readFileSync('f.txt','utf8')))"
   或浏览器 F12 Console 粘贴回车
```

**JSFuck 识别**：全篇只有 `[]()!+` 六种字符，没有任何字母数字 → JSFuck，执行即得结果。

**⚠️ 反直觉提醒**：文件名/变量名越说"自己是假的"（如 f@k3=fake），越可能是真线索。

## 三、常用命令速查（每条都解释）

| 命令 | 含义 | 什么时候用 |
|---|---|---|
| `curl -s URL` | 抓取网页内容，`-s`=静默（不显示进度条） | 看一个页面/接口返回什么 |
| `curl -s URL -o 文件` | 抓取并**保存到文件** | 下载 JS/源码/附件 |
| `curl -s URL -H "头: 值"` | 带自定义请求头 | 伪造 UA、Referer 等 |
| `grep -in "词" 文件` | 在文件里搜词，`-i`=忽略大小写，`-n`=显示行号 | 在源码里找关键词 |
| `grep -rin "词" 目录` | 递归搜整个目录（`-r`） | 一次搜完一堆 JS 文件 |
| `grep -En "正则"` | 用**扩展正则**搜索（`-E`） | 搜复杂模式（花括号等） |
| `wc -l 文件` | 统计文件行数 | 快速判断文件大小 |
| `python -c "代码"` | 直接跑一段 Python | 处理数据、解码 |
| `git-dumper URL 目录` | 从暴露的 .git 下载整个仓库 | .git 泄露题 |
| `git log --oneline --all` | 列所有提交（`--all`=全部分支） | 看历史提交 |
| `git log -p --all` | 看每次提交的**具体改动**（`-p`=patch补丁） | 翻出被删掉的 flag |
| `git show <提交号>` | 看某次提交内容 | 精确定位某个版本 |

## 四、flag 狩猎正则（重点 ★）

> 背景：flag 常被伪装成 `F|L|A|G`、`F-L-A-G`、`f1ag` 等，字面搜 "flag" 会被挡掉。所以要多角度搜。下面每条都拆开解释。

### ① 直接搜 flag 格式前缀
```bash
grep -rin "nssctf\|ctf{"
```
- `-r` 递归目录 ｜ `-i` 忽略大小写 ｜ `-n` 带行号
- `"nssctf\|ctf{"`：两个词**用 `\|` 连接 = "或"**（搜到任意一个都算命中）
- **用途**：大部分平台 flag 有固定格式（NSSCTF{...}、flag{...}），搜前缀最直接。⚠️ 注意花括号 `{` 在正则里要小心（见③）

### ② 搜 flag 单词变体
```bash
grep -rin "flag\|fl4g\|f1ag"
```
- `fl4g` / `f1ag` 是 `flag` 的"数字替换"写法（`4`→a，`1`→l）
- **局限**：会被 `F|L|A|G` 这种**插分隔符**的写法挡掉——所以还要配合③

### ③ 搜花括号包裹的长字符串（这题的关键 ★★★）
```bash
grep -rEn "\{[A-Za-z0-9_!-]{4,}\}"
```
逐字符拆解：
- `\{` — `\` 是转义符，让 `{` 变成**普通字符**（正则里 `{` 本来有特殊含义，见下）
- `[A-Za-z0-9_!-]` — **字符类**：允许这些字符中的**任意一个**（大小写字母、数字、下划线、感叹号、连字符）
- `{4,}` — 前面的字符类**重复 4 次及以上**（`{n,}` = 至少 n 次）
- `\}` — 结束花括号
- 整体含义：**匹配 `{` + 至少4个"像flag的字符" + `}`**

> 为什么这是王牌：**flag 内容基本都躺在花括号里**。不管它写没写 "flag" 字样，`{一串字符}` 一搜一个准。导弹迷踪这题就是靠它中的。

### ④ 搜"成功提示语"（flag 常和它同屏）
```bash
grep -rin "win\|got\|pass\|complete\|level"
```
- 游戏/判定逻辑里，通关提示词（`GOT`、`WIN`、`COMPLETE`）旁边 90% 跟着 flag。

### ⑤ 万能一键搜索（常备武器 ★★★）
```bash
grep -rEin 'nssctf\{|flag\{|ctf\{|f[|_ .0-9-]{0,3}l[|_ .0-9-]{0,3}a[|_ .0-9-]{0,3}g|\{[A-Za-z0-9_!\-]{8,}\}|win|got|pass|complete|success'
```
把 ①~④ 全部用 `|`（或）合成一条，一次搜完所有可能性。

- **模糊 flag** `f[|_ .0-9-]{0,3}l[|_ .0-9-]{0,3}a[|_ .0-9-]{0,3}g` 是核心：
  - 字母间可夹「竖线/下划线/空格/数字/连字符」最多 3 个
  - 一次命中：flag、FLAG、fl4g、F|L|A|G、F-L-A-G、F_L_A_G、f 1 a g
- **代价**：误报多（`pass`/`level`/`complete` 会混进来）——但搜一次+肉眼扫一眼，比搜好几次快。
- **使用口诀**：先跑万能 → 没找到再缩小精搜 `NSSCTF{` 前缀。

### ⚠️ 正则避坑小抄
| 写法 | 含义 |
|---|---|
| `a\|b` | 或（BRE 语法，`\|` 表示或） |
| `a|b` | 或（ERE 语法，配 `-E` 用，`|` 直接表示或） |
| `\{` | 把 `{` 当普通字符（转义） |
| `{4,}` | 重复至少 4 次（**这是正则语法**，花括号不加反斜杠时才有这含义） |
| `.` | 任意单个字符 |
| `.*` | 任意多个字符（贪心） |
| `[abc]` | a、b、c 中任一个 |
| `^a` | 行首是 a |
| `a$` | 行尾是 a |
