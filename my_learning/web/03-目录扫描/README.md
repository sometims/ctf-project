# 📂 03 · 目录扫描

## 一、题型概述

当页面没直接给入口时，**用字典爆破目录/文件**，往往能扫出隐藏的后台、备份、源码、配置文件、flag 文件。是信息收集的标配动作。

## 二、常考考点

- **字典扫描**：对 `/admin`、`/backup`、`/flag`、`/robots.txt`、`/.git` 等常见路径枚举。
- **假 200 判断**：很多框架对不存在路径返回 200 + 同一套兜底页（如返回首页 HTML），必须靠"内容差异"而非状态码判断，否则满屏假 200。
- **响应特征识别**：根据页面大小、是否含特定文案区分"真存在"与"兜底页"。
- **常见隐藏端点**：`/admin`、`/api`、`/source`、`/www.zip`、`/flag.txt`、`/.git`、`/phpinfo.php`。

## 三、解决方法 / 通用套路

1. 先手测几个常见路径（一次性 shell 循环）。
2. 上工具跑字典；**务必开启"假 200 过滤"**（见 `mini_scanner.py`）。
3. 扫到源码/备份 → 读它（进入信息泄露/代码审计链路）。
