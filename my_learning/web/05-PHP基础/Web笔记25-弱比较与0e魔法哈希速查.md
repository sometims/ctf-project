# Web笔记25 · 弱比较与 0e 魔法哈希速查

> 主题：PHP `==` 宽松比较的类型转换机制、0e 魔法哈希原理与选型
> 关联实战：qsnctf 40724（MD5 弱比较带约束）、TYctf（sha1 弱比较）、qsnctf "It is DT's day"（真碰撞）

## 一、== 与 === 一句话区别
- `==`（宽松）：先做类型转换再比值 → 容易被骗
- `===`（严格）：值 + 类型都必须相同，不做转换 → 骗不了

## 二、== 的类型转换方向（谁换谁）★ 核心
| 两边是什么 | 谁被转换 | 例子 |
|---|---|---|
| 数字 vs 字符串 | **字符串 → 数字** | `0 == "abc"` → true（"abc"→0）|
| 数字字符串 vs 数字字符串 | **两个都 → 数字** | `"0e830..." == "0e462..."` → 都→0.0 → true |
| 普通字符串 vs 普通字符串 | 都不换，按字符串比 | `"abc" == "abd"` → false |
| 字符串 vs 布尔 | 字符串 → 布尔 | `"0" == false` → true |

口诀：**只要有一边"像数字"，弱比较就往数字方向靠**。不是"跟随另一边的类型"，是看字符串自己像不像数字。

## 三、0e 魔法哈希原理
- 字符串 `0e830400451993494058024219903391` 符合科学计数法格式：`尾数e指数`
- = 0 × 10^8304... = **0**（尾数是 0，指数再大也是 0）
- 两个不同的 0e 串，转数字后都是 0.0 → `0.0 == 0.0` → true
- 前提：代码用的是 `==`；`===` 直接比字符串原文，不同就是不同

## 四、常用魔法哈希表（背下来）
| 输入 | md5 |
|---|---|
| `QNKCDZO` | `0e830400451993494058024219903391`（纯字母，配 ctype_alpha）|
| `240610708` | `0e462097431906509019562988736854`（纯数字，配 is_numeric）|
| `s878926199a` | `0e545993274517709034328855841020` |
| `s155964671a` | `0e342768416822977524854789101267` |
| `aaroZmOk`（sha1）| `0e66507019969427134894567494305185566735` |

## 五、选型决策表（做题第一步看比较符）
| 场景 | 用什么 | 原理 |
|---|---|---|
| `md5($a) == $b`（弱）| 0e 魔法哈希 / 数组（`$a[]=1`）| 假相等：数值上都是 0 / 都是 null |
| `md5($a) === $b`（强）+ 无字符限制 | **fastcoll 真碰撞** | 两输入的 md5 字节级完全相同 |
| `md5($a) === $b` + 有字符限制 | 基本无解 | 碰撞块是二进制，没法既碰撞又全字母 |

## 六、约束条件决定手法（重要）
- 40724 题：v1 必须 `ctype_alpha`（纯字母）+ v2 必须 `is_numeric`（纯数字）→ **数组绕过被卡死**（ctype_alpha(数组)=false）→ 只能 0e，且得挑"字母版"和"数字版"魔法哈希
- 无约束题：数组绕过最省事（md5([])=null，null==null 秒过）

## 七、0e 假相等 vs fastcoll 真碰撞
- **0e**：骗 PHP 的比较逻辑（两个**不同**的 md5 值，数值上碰巧相等）
- **fastcoll**：货真价实（两个输入的 **md5 完全一样**，任何比较都过）
- fastcoll 只针对文件/二进制块，字符约束题进不去；它适合上传题（文件 MD5 判重）

## 八、相关坑位
- `strcmp($a,$b)` 在 PHP7 传数组会返回 null，`null == 0` → 绕过
- `"abc" == 0` 在 PHP7 为 true（任意非数字字符串转数字=0）；PHP8 已修
- 看到 `md5()`/`sha1()`/`strcmp()` 先问：`==` 还是 `===`？
