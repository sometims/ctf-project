# 🐘 05 · PHP 基础

## 一、题型概述

**不是漏洞，是"读懂 PHP 题"的底层语法速查**。反序列化、文件包含、RCE、上传这些 PHP 栈题，都建立在对 PHP 语法（超全局变量、危险函数、类型特性）的理解上。当作字典随时翻。

## 二、常考考点

- **超全局变量**：`$_GET` / `$_POST` / `$_REQUEST` / `$_COOKIE` / `$_SESSION` / `$_SERVER` / `$_FILES`。
- **危险函数**：`eval` / `system` / `exec` / `include` / `unserialize` / `assert` / `preg_replace(/e)`。
- **变量覆盖**：`extract()`、`parse_str()`、`$$` 变量-variable。
- **类型特性**：弱类型比较（`==` vs `===`）、`0=="abc"`、`"admin"==0` 等 Magic Hash。
- **读题三步法**：找输入点 → 看怎么处理 → 找危险落点。

## 三、解决方法 / 通用套路

1. 遇到 PHP 题先定位**输入如何进入危险函数**。
2. 不确定语法就回本笔记查超全局变量 / 危险函数清单。
3. 弱类型比较常是"登录绕过""属性覆盖"题的突破口。
