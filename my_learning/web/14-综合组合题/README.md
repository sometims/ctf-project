# 🧩 14 · 综合组合题

## 一、题型概述

真实比赛里大量题目**不是单一考点**，而是把 2~3 个知识点串成一条链。本分类专门收这类"组合拳"，用来检验知识图谱是否成体系。

## 二、常考组合模式

- **穿越读源码 → 拿到密钥/线索 → 伪造身份/触发下一步**（文件读取家族 + Session/反序列化）。
- **信息泄露 → 代码审计 → 反序列化/POP 链**。
- **SSRF → 打内网 → 读内部接口 flag**。
- **文件包含读源码 → 发现可利用点 → RCE**。

## 三、解决方法 / 通用套路

用「**三问法**」破局：
1. **目标文件/数据在哪？**（先确定终点）
2. **被什么堵住了？**（WAF/黑名单/解析限制）
3. **有没有侧门？**（别的入口/等价写法/内网通道）

每一步对应图谱里的一个分类，缺哪块就回哪块补。
